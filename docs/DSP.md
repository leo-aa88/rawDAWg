# rawDAWg — DSP and instrument specification

The DSP engine is custom Rust, independent of UI, CPAL, CLAP and VST3. The primary UX is immediate intuitive manipulation; advanced parameters remain available. Implement actual algorithms, not renamed presets or effects that all perform the same operation.

## 1. Common contracts

- Planar f32 audio; normalized control values mapped to physical units by immutable descriptors. Frequency/log controls exponential mapping; gain in dB, time in seconds/ms; support zero/bypass explicitly where logarithm undefined. Clamp/validate every external parameter, reject non-finite and invalid state.
- `prepare` off RT allocates all delay lines, FFT plans, sample/wavetable banks, voice state, scratch. `process` receives variable frames and sorted sample-offset events; process spans or per-sample as needed. `reset` RT-safe and bounded. Sample rate changes reprepare, clear or migrate appropriate state off RT. No memory operations violating ARCHITECTURE.md.
- Anti-aliasing: bandlimited oscillators, mipmapped wavetables, oversample nonlinear waveshaping (2x/4x selectable, properly low-pass decimate), bound modulation frequency and reject impossible parameter ranges. Avoid excessive aliasing in FM/granular with appropriate bandlimiting/oversampling; measure under tests, not promise ideal alias-free arbitrary distortion.
- Continuous control smoothing: default 5–20 ms for gain/pan/frequency/knob changes; configure per descriptor. Waveform table swaps short crossfade (default 5–10 ms). Do not smooth deliberately stepped modulation/automation or note attack beyond configured musical envelope; coefficient stability across modulation. Bypass click-free ramp, align dry/wet latency.
- Finite check on graph boundary, denormal suppression or tested tiny-value flush, DC blocking where appropriate (editable waveform DC removal on by default). Do not clamp every internal bus to [-1,1]; preserve headroom, detect overload, isolate offending node, reset when necessary, count/report. Master and preview limiter defaults protect output; offline float unprotected only explicitly chosen. No guarantee against hearing damage at arbitrary hardware volume.
- Determinism: store PRNG algorithm version and seed; use a fixed algorithm (e.g. ChaCha8 with pinned version and explicit byte seeding), stable iteration order; separate mutation RNG from per-voice noise RNG, derive seeds from patch + note/event ID. Reset renders reproducibly on same build, rate and settings. Across OS/CPU compare numerical tolerance, not universal bit identity. Randomization happens off RT; runtime stochastic synthesis uses bounded preinitialized PRNG state.

## 2. Flagship synthesizer: default patch and voice model (SYN-01, SYN-10)

Default patch: one audible sine/soft saw wavetable layer, A4 = 440 Hz, equal-tempered pitch `440 * 2^((midi-69)/12)`, amp envelope attack 5 ms, decay 120 ms, sustain 0.75, release 180 ms, open low-pass, no extreme FX, gain matched at moderate audition level. Immediately playable after adding instrument, no blank modular graph. Support 1–4 layers; each layer can choose one generator below. Per-layer level/pan/coarse and fine tuning/phase/unison (1–8, total budget), deterministic/random phase option. Stereo spread with normalization; unison not uncontrolled gain multiplication.

| Mode | Minimum real implementation |
|---|---|
| Wavetable | Cyclic 2048-sample editable base waveform, mip levels, interpolated read and position morph across 2–16 frames |
| Subtractive | Bandlimited sine/triangle/saw/pulse/noise, pulse width, low/high/bandpass/notch resonant filters and envelopes |
| FM/PM | At least four operators with selectable ratios/index and routable acyclic operators, explicit feedback delay; expose phase modulation accurately rather than calling it true FM indiscriminately |
| Additive | Up to 128 editable partial amplitudes/phases, pitch-aware limit at Nyquist, harmonic and optional detuned partial mode |
| Granular | Source sample/wavetable, grain size 5–500 ms, density, position/jitter, pitch/spread, windows; bounded active grains (e.g. 128 per instance) and pool |
| Physical model | Plucked string Karplus–Strong/digital waveguide with damping, excitation, fractional delay tuning and bounded feedback |

Per-voice amp envelope ADSR with optional custom multisegment curve (up to 32 points; time monotonic, explicit sustain/loop/release semantics); filter envelope, LFOs (free, beat-sync, arbitrary curve, sample/hold), key tracking, velocity, aftertouch, mod wheel, per-note expression where available. Mod sources may target compatible parameters at control or audio rate, bounded by compiled graph. Global modulation shared; per-voice state isolated. Voice modes mono retrigger, mono legato/portamento, poly. Allocate fixed voice slots; choose oldest released, then quietest/oldest active with deterministic tie break; short fade or preallocated tail to prevent clicks. Note identity and sustain as ARCHITECTURE.md; pitch bend default ±2 semitones configurable, bend can target channel or note. Release all voices on reset/panic. Per-patch tuning transpose, detune, optional equal-tempered reference frequency; root musical pitch preserved by default in mutation (intentional pitch tools may alter it).

## 3. Waveform sculpting (SYN-02, SYN-06)

The main canvas represents **one cycle of the stored waveform**, not just a passive oscilloscope of output. Provide separate live-output scope so user knows distinction. x = normalized cyclic phase [0,1), y = amplitude [-1,1]. Multiple cycles may be displayed for context but edits affect canonical cycle. Mouse gesture operates on circular sample indices with wrap at seam; interpolate between sampled pointer points. Brush radius and intensity visible; wheel changes radius when canvas focused; modifier or secondary control adjusts strength. Left drag active tool; undo/redo at gesture granularity. `Draw` sets local amplitude via smooth brush, `Deform` shifts local samples vertically, `Smooth` applies circular low-pass, `Sharpen` adds bounded high-pass difference, `Stretch` remaps local phase with monotonic warp, `Distort` applies localized wavefold/waveshape, `Noise` adds seeded localized noise. Tool preview shows affected radius, and double-click/reset returns to selected basic wave only via undoable command. All must produce measurably different audio for suitable input.

Pipeline: raw editable cycle → optional DC removal → peak/RMS guard with reversible edit representation → FFT → spectral edits → pitch-appropriate harmonic truncation → mipmapped oscillator tables (levels for upper fundamental bands) → interpolated playback. Keep raw cycle editable; stored canonical recipe/arrays plus algorithm version; never destructively overwrite it with a playback mip. Ensure periodic interpolation at seam; optional smoothing at seam, not duplicated endpoint. Harmonic limits use actual voice pitch incl bend; blend levels near boundaries, oversample where modulation warrants. Off-thread regenerate only dirty frames/tables, preallocate RT crossfade path. User hears new table while holding note, no retrigger. Aim for update-to-audio p95 ≤50 ms for default patch on reference machine. Coalesce rapid pointer motion, keep final gesture. If heavy spectral edit takes longer, show unobtrusive progress and continue old audible patch, never freeze audio.

Spectral view: harmonic number/frequency ruler, magnitude (linear or dB view), optional phase lane. Add/erase/smooth/paint partials; preserve conjugate symmetry for real IFFT and handle DC/Nyquist bins correctly. Phase editing optional toggle, default hidden. Update cycle and harmonic view consistently; no misleading visual-only edits. Frame editor supports 2–16 waveform frames with ordered position keyframes, smooth interpolation over morph position; position automatable and modulatable by envelopes/LFO/time. UI can scrub frame and audition motion. Provide base waveform presets and import short sample segment as cycle (explicit crop, resample, optional normalize). Do not treat arbitrary long audio clip as a periodic oscillator unless user chooses it.

## 4. Randomization, mutation and breeding (SYN-03, SYN-04)

One visible `Randomize sound` button, adjacent `Chaos` 0–100 slider (default 35), `Lock` controls and Undo. Defaults should create usable changes, not constant silence, extreme loudness, ultrasonic-only signals or arbitrary out-of-range filter values. Parameter descriptors include semantic category, distribution, safe bounds and lock key. Generate bounded mutations in perceptual domains (log frequency/time, dB gain, categorical algorithms). At low chaos perturb a few continuous params slightly; middle chaos changes wave shape, envelopes, modulation, effect settings; high chaos may replace oscillator/FX topology within graph/cost limits. Chaos=0 returns unchanged patch, with no misleading undo entry. Default locks: master output safety, tuning/root pitch and routing to DAW. User can lock/unlock individual categories (wave, pitch, envelope, filter, modulation, effects, topology) and specific parameters. Locks survive mutation, breeding and all descendants. Explicit pitch unlock permits octave/coarse changes within range. Preserve lock semantics on topology mutation; if a locked node would be removed, retain it or reject candidate.

Generate deterministic candidate from parent snapshot + seed + amount + locks, validate graph, approximate cost and render short audition offline off RT at fixed notes/velocity; reject NaN/Inf, silent candidates except intentional silence mode (not default), unsafe gain, pathological runtime cost. Use bounded attempts (e.g. 8), fall back to safe smaller mutation or report no valid candidate. Audition level matched with bounded preview gain (not secretly modify patch or normalize exports). An extreme mode may intentionally create noise or atonal textures but still respects safety/limits. Randomness button never affects transport pitch/timing unless explicitly automating.

Evolution screen: current parent and 3×3 descendants, each generated deterministically by parent/seed/generation/index. Show waveform thumbnail and concise sound tags; clicking card selects and auditions, keyboard navigation works; preview via held note/chord where possible, optionally loop a short default phrase. Hover preview optional and off by default to avoid noise. `Evolve selected` creates nine new real patches based on selected parent; `Breed` selects two, blends compatible descriptors and waveform frames, chooses validated discrete topology, honors locks from active parent, produces bounded children. Keep branch history and back/forward; compare parent/child, favorite, commit into active instrument as one undoable command or cancel. Cache patch previews keyed by patch hash, audition rate/note/velocity; worker cancellation/limits, never audio files on callback. Visual differences alone not acceptance: ensure non-identical audible buffer/features for nontrivial changes.

## 5. XY morphing (SYN-05)

Four corners hold saved patch snapshots; weights `(1-x)(1-y), x(1-y), (1-x)y, xy` with x,y clamped to [0,1]. For same topology interpolate continuous params in physical/perceptual domain, waveform frames in aligned phase/time domain or spectrum with documented choice, discrete choices use hysteresis. For incompatible topologies use bounded parallel render crossfade of prepared corner instances with voice synchronization, normalized weights and CPU admission; collapse zero-weight corners when safe, crossfade activation, no allocation while moving. If cost exceeds budget require compatible morph or fewer corners with clear message, not fake interpolation. At exact corners output that corner patch (same note state/reset semantics). Drag while note plays; automate x/y separately as points, record pointer movements with coalescing and sample timestamps. `Freeze as preset` stores resulting compatible patch or explicit morph rack with corners, not an incorrect flattened approximation. Undoable assignments, gestures and recorded automation.

## 6. Advanced modular editor (SYN-07)

Optional `Advanced` reveals nodes/ports with audio (mono/stereo), normalized control (global/per voice, control/audio rate), events. Standard nodes: oscillators, noise, sampler, envelopes/LFOs, math, mix/split, filters, gain, delay, waveshaper, FFT-based nodes where prepared, output. Per-voice graph then global graph; reductions explicit (sum/max/last, etc.) and adapters for mono/stereo/control/audio. Compiler validates port types, dependency order, maximum nodes/edges and total processing cost, rejects invalid cycles; explicit delayed feedback per architecture. No implicit feedback or arbitrary blocking calls. Editing graph compiles off-thread, old graph continues if invalid; show bad edge/reason and retain last valid playable revision. Modulation can target compatible parameters, including other modulators if no instantaneous cycle. Advanced modulation matrix lists source/target/depth/polarity/curve/rate; user can drag a modulator onto a knob. Native UI still provides common macros without advanced view.

User DSP expression nodes: bounded expression language only (no arbitrary Rust, OS access, network, imports, recursion, loops, dynamic allocation). Grammar literals, input/control/time variables, + - * /, min/max, abs, sin/cos/tanh, exp/log with checked domain, clamp, comparisons and bounded select. Optional fixed `z1`/delay node separate explicit state. Parse/validate off-thread, compile to stack/register bytecode with fixed max 256 instructions and 64 stack slots per sample/node (default), enforce cost budget, no runtime parse. Invalid division/domain returns finite safe value + diagnostic counter, no panic. Include editor examples (e.g. `tanh(x * drive)`), immediate audition and undo, source and bytecode version saved; never evaluate untrusted native code.

## 7. Sampler and SoundFont (SYN-09)

Sampler supports mono/stereo WAV/FLAC/MP3 decoded to prepared asset; pitch relative root, one-shot/gated, start/end and loop bounds, forward loop and crossfade, gain/pan/ADSR, polyphony, interpolation with bandlimited resampling for high pitch where needed. Drag audio into channel rack creates sample instrument; drag into playlist creates audio clip (clear target). Loop region valid and sample bounds checked. SF2 importer parses RIFF `sfbk`, preset/instrument zones, sample data, global/local zones, key and velocity ranges, root/scale tuning, attenuation, pan, loop modes, volume envelope, basic filter and supported modulators. Bank/program selection, bank 128 percussion where present. List supported SF2 generators/modulators in help, show warning on unsupported features, handle invalid files with errors. Tests use original generated minimal SF2 fixture; no bundled copyrighted General MIDI bank unless license cleared. Imported MIDI program mapping can use user-selected SF2 bank or native fallback with explicit unmapped programs.

## 8. Native effects (FX-01/02/03)

Each effect implements prepare/process/reset/latency/tail and parameter descriptors, wet/dry when appropriate, enable/bypass, presets and simple/advanced UI. Parameters bounded; sample-rate aware. Presets are actual distinct settings or algorithms, not identical renamed sounds. Effect suite acceptance includes impulse/frequency/time-domain tests for each algorithm and listening tests.

| Effect / algorithm | Simple controls / required behavior |
|---|---|
| Reverb (room, hall, cathedral) | Size, decay (RT60), mix, damping, pre-delay; early reflections + feedback delay network/diffusion. Distinct topology/parameter sets and measurable decay/density. |
| Plate | Diffusion/tank-style algorithm with plate-like dense tail and damping. |
| Spring | Dispersive all-pass/delay or waveguide approximation, characteristic ringing; clearly modeled, no fake physical claim. |
| Shimmer | Pitch-shifted feedback with damping, gain bounds, limiter and clear pitch setting. |
| Convolution | Load user IR, mono/stereo channel mapping, partitioned FFT, latency reported, IR length/memory bounded (initial max 30 s), trim/normalize optional off-thread. |
| Reverb curve edit | Draw decay envelope/control shape with constrained stable energy decay; influence feedback/damping stages or convolution envelope explicitly, no unstable gain automation. |
| Delay | Time or beat sync, feedback/mix, stereo/ping-pong; tape-style modulation/saturation, multitap editor (up to 16), reverse segment buffers with reported latency. Tap drag changes time/gain. |
| Compressor | Threshold dBFS, ratio, attack, release, knee, makeup, RMS/peak detector, external sidechain and gain reduction meter; envelope stable. |
| Limiter | Ceiling dBFS, release, lookahead; true-peak mode via ≥4x oversampled peak estimate and appropriate reconstruction/latency, report estimated dBTP; validate independently, avoid unsupported standards certification claims. |
| Parametric EQ | At least 8 bands, bell, shelves, LP/HP, notch; frequency/Q/gain, draggable points, response plot, stable biquad/coefficient interpolation. |
| Distortion | Tube/tape nonlinear curves, hard/soft clip, wavefold, bitcrush (bit depth + rate); oversampling for nonlinear modes where appropriate, output trim. |
| Per-band distortion | Paint gain/drive/mix across bands; phase/latency-aligned crossover or STFT implementation, predictable recombination at unity. |
| Chorus | Modulated delay voices, stereo spread, depth, rate, mix; interpolated delay. |
| Phaser | Modulated all-pass stages, feedback, mix; stable coefficients. |
| Flanger | Short modulated delay + feedback, rate/depth, comb response, safe feedback. |
| Gate | Threshold, hysteresis, hold, attack/release, range, detector/sidechain when supported. |
| Pitch/formant | Pitch shift independent of duration (phase vocoder/WSOLA hybrid or suitable tested algorithm); distinct formant-preserve/shift control, latency/tail reported, polyphonic audio usable. |
| Granular FX | Buffered input grains, density/size/position/pitch/jitter/window, bounded buffer/voices, latency if any. |
| Spectral FX | STFT with window/overlap-add reconstruction; freeze, smear, bin gain/phase manipulation; bypass/null and latency tests. |
| Stereo processor | Equal-power mono pan, stereo balance, width via mid/side, mono compatibility and correlation meter. |

Native presets: at least 3 meaningful presets per effect family, reverb includes every named mode with at least one preset, delay all modes. Flagship synth includes at least 24 original presets across specified categories; at least 8 unusual sounds; sample/SF2 demo content generated or license-cleared. Preset preview calibrated, no auto-play on app launch.

Effect rack experiments: randomize rack with Chaos and locks; mutate parameters/order or add/remove allowed effects within resource limits; no removal of locked safety/routing nodes. Morph same topology by descriptors and different topology by latency-aligned bounded crossfade; explicit parallel paths/sidechain; automation of macros. Randomization uses same versioned seeded framework as synth. Bypass true signal path (latency alignment retained during playback), off/enable semantics documented. Tail handling: report finite estimate in frames or unknown/infinite; offline export uses user tail duration or bounded automatic cap, no unbounded render. Native master protection can be bypassed explicitly; preview always bounded.
